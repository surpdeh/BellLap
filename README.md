# BellLap

Android app that records the finishing order of cycling criteriums and other multi-lap races:

1. It hears the **bell lap** bell.
2. It arms the camera.
3. It starts recording when the **chequered flag** appears.
4. It marks each **finish-line crossing**.
5. It gives commissaires a frame-accurate review tool.
